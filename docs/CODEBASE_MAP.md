# نقشه کدبیس

## وضعیت Graphify
**بررسی Graphify انجام نشده.** Graphify MCP در این محیط Cursor در دسترس نیست؛ خروجی Graphify جعل نشده است. این فایل یک نمای دستی سطح‌بالاست، نه جایگزین تحلیل Graphify.

پس از ایندکس مخزن در Graphify (با مجوز کاربر)، این سند باید با یافته‌های واقعی ابزار به‌روز شود.

## نمای دستی فاز A (موقت)
- `apps/web/app` — routeها
- `apps/web/components` — اجزای مشترک UI
- `apps/web/features` — منطق صفحه‌ای analysis/markets/buyers/feasibility/admin
- `apps/web/lib/api` — کلاینت و mock-adapter
- `apps/web/lib/i18n/fa.ts` — برچسب‌های فارسی
- `apps/web/types` — قراردادها
- `apps/web/fixtures` — سناریوهای آزمایشی
